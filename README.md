#  KikeParking - Gestión Colaborativa de Parqueaderos

##  Descripción del Proyecto
KikeParking es un prototipo de aplicación móvil enfocado en resolver el reto urbano de la saturación del espacio público en el Valle de Aburrá (específicamente en zonas como Laureles y Provenza). 

El proyecto propone un sistema de gestión de parqueaderos basado en una **red colaborativa**. Su objetivo es conectar de manera segura a ciudadanos que tienen garajes privados (y que pasan gran parte del día vacíos) con conductores que necesitan un lugar de estacionamiento. Con esto buscamos ofrecer una alternativa eficiente, económica y socialmente responsable para la ciudad.

##  Tecnologías Utilizadas
Este prototipo fue desarrollado utilizando tecnologías web estándar (Frontend), sin el uso de frameworks adicionales:
* **HTML5:** Para la estructura de la aplicación.
* **CSS3:** Para los estilos y el diseño visual (adaptado para simular una vista móvil).
* **JavaScript (Vanilla):** Para la lógica de interacción, el manejo de eventos y la simulación del registro de usuarios.

##  Estructura del Proyecto
El proyecto cuenta con la siguiente estructura básica de archivos:

```text
KikeParking/proyecto/
├── assets/         # Carpeta con logo.
├── index.html      # Archivo principal (Punto de entrada de la app)
├── script.js       # Lógica de la aplicación y guardado local de datos
└── style.css       # Hojas de estilo
```
##  Instrucciones de Instalación y Ejecución
La aplicación no requiere la instalación de servidores locales ni dependencias complejas. Para ejecutarla, siga estos pasos:

* Clone este repositorio o descargue el código en formato .ZIP haciendo clic en el botón verde "Code" -> "Download ZIP".

* Descomprima el archivo descargado en su computadora.

* Abra la carpeta KikeParking/proyecto.

* Haga doble clic sobre el archivo index.html. Este se abrirá automáticamente en su navegador web predeterminado (se recomienda usar Google Chrome o Mozilla Firefox).

##  Credenciales y Pruebas (Aviso Importante)
Para propósitos de esta entrega final, la conexión a bases de datos externas (SQL/Firebase) ha sido omitida. El sistema utiliza persistencia de datos local (simulada) mediante JavaScript.

Para probar el sistema de inicio de sesión:

* Al abrir la aplicación, diríjase a la opción de Registrarse.

* Ingrese datos de prueba (cualquier usuario y contraseña) para crear una cuenta. El sistema guardará esta información internamente.

* Vuelva a la pantalla de Inicio de Sesión e ingrese las credenciales que acaba de crear. ¡Y listo! Podrá acceder a las funcionalidades de la aplicación.
